# Academic Records Management System

A Python command-line application for managing students, courses, and course completions.

## Features

- Add new students
- Search students by name
- Search courses by code, name, or teacher
- Record course completions and grades
- Update existing grades
- Display student academic records
- Calculate completed credits
- Calculate credit-weighted average grades

## Technologies

- Python
- File I/O
- Dictionaries and Lists
- Datetime Validation
- Command Line Interface (CLI)

## Example Menu

```text
1) Add student
2) Search student
3) Search course
4) Add course completion
5) Show student's record
0) Exit
```
