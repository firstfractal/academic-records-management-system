# Academic Records Management System

A Python command-line application for managing students, courses, course completions, and academic records.

Developed as a course project for **CT60A0250 Fundamentals of Programming** at LUT University.

---

## Features

- Add new students
- Automatically generate student IDs and email addresses
- Search students by first, middle, or last name
- Search courses by course code, course name, or teacher
- Record course completions and grades
- Update course grades when a higher grade is achieved
- Validate dates and grades
- Display complete student academic records
- Calculate completed credits
- Calculate credit-weighted average grades
- Store data using text files

---

## Technologies Used

- Python
- File I/O
- Dictionaries and Lists
- Datetime Module
- Input Validation
- Command Line Interface (CLI)
